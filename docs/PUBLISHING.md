# Publishing and maintenance

This repository is a standalone public portfolio, **not** a clone of the private ENNEAD application.

## Published material

- Original ENNEAD cover image and README.
- Abbreviated technical documentation and engineering case studies.
- A standalone static HTML presentation using no backend or private production code.

## Optional GitHub Pages

Repository **Settings → Pages → Deploy from a branch → main / (root)**.

Once activated by the owner, the site can render the repository's `index.html`. Verify the rendered page and navigation after activation. No Pages deployment is claimed here.

## Future updates

Use a separate public-release staging area. Review all assets, text and version history before committing. Add *actual* app screenshots only after thorough personal-data and metadata checks. Never link the private repository as a remote or include its `.git` directory.
