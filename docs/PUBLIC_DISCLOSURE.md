# Public Disclosure Policy

This repository is a **curated public showcase**, never an automatic mirror of the private ENNEAD source repository.

## May be published after review

- Original project branding and publicly cleared descriptions.
- High-level diagrams without private APIs, schemas or architectural contracts.
- Bounded, verified descriptions of actual functionality.
- Sanitized screenshots and videos featuring fictional, non-sensitive data.
- Standalone generic examples explicitly approved for publication.

## Must remain private

- ENNEAD source code, binaries, internal Git history and unpublished experiments.
- Credentials, API keys, tokens, environment variables, private prompts or configurations.
- Detailed interfaces, internal algorithms, private project plans and unpublished research material.
- Actual project notes, private account identifiers, absolute local paths and personal files.

## Before each public update

1. Compare proposed files with the approved manifest; never import the private repository wholesale.
2. Inspect images and videos at full resolution, including visible notifications and path text.
3. Manually search for names, contacts, accounts, secrets, URLs and local workspace details.
4. Run automated secret scanning when available; do not treat it as a complete guarantee.
5. Check Git history as well as present files; removing a later file does not erase its earlier commits.
6. Label concepts and mock-ups clearly; never advertise them as shipped features.

The showcase has no general open-source license. See [NOTICE](../NOTICE.md).
